Plan a web app to improve records discovery process on discogs.

Idea: One can set up filters to limit available releases, for example funk from 1960 till 1979, available from Europe based sellers with offers > 10 and price below <10eur. Once filter is set, app shows/creates a playlist from reference links avaialble on discocs, usually there are a few videos from youtube.
Goal: Find interesting records by filters via prepared playlists
Challanges:
* need to track what was 'reviewed' already (added to wantlist or discarded)
* some releases may have apple music or something else (?) instead of youtube links
* it should be easy to mark release/record as discarded/not-interested or add it to wantlist
* discovery process should be as smooth as possible, "one button expirience"
